# My JS Learning & Logic Hub 🚀

Is repository mein maine JavaScript ke wo saare concepts implement kiye hain jo maine apni learning ke dauran seekhe hain. Ye ek single-file project hai jo functional logic aur clean code par focus karta hai.

### 🧠 Topics I have covered:
* **ES6+ Syntax:** Arrow functions, Template literals, and Destructuring.
* **State Management:** Using the Spread operator (`...`) to manage data without mutating the original array.
* **Array Methods:** 
  - `.filter()` for searching logic.
  - `.map()` for rendering UI elements.
  - `.reduce()` for calculating statistics.
* **Asynchronous JS:** Using `async/await` and `fetch()` to handle API data.
* **DOM Logic:** Efficiently updating the UI based on data changes.

### 🛠 How to view this:
1. Open `index.html` in any browser.
2. Check the **Console (F12)** to see the data flow and logic execution.
